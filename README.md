# Ascent

A premium Life RPG productivity application.

## Overview

Ascent transforms daily routines, habits, and tasks into an immersive gaming experience. It transcends traditional to-do lists by bringing the mechanics of a Role-Playing Game into everyday life. Users complete quests, earn XP, level up, maintain streaks, and unlock achievements as they progress toward their goals.

## Capabilities

- **Quest Log:** Turn daily chores and tasks into rewarding quests.
- **Skill Tree:** Visualize proficiency across different life domains with dynamic progress tracking.
- **Progression System:** Earn XP and level up by completing tasks.
- **Streaks & Combos:** Maintain streaks to multiply rewards and stay motivated.

## Technologies

The Ascent ecosystem consists of a native Android application and a marketing website.

### Android Application

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM with Hilt for Dependency Injection
- **Local Storage:** Room Database, DataStore
- **Authentication:** Firebase Auth
- **Image Loading:** Coil

### Marketing Website

- **Framework:** Astro
- **Language:** TypeScript
- **Styling:** Tailwind CSS
